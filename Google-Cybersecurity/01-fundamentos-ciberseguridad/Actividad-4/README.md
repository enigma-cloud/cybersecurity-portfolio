# Network Hardening Assessment

Activity on network hardening practices and security risk assessment.

## Description

Security risk assessment for a social media organization that recently suffered a major data breach caused by undetected vulnerabilities. The goal is to identify common network hardening tools and propose methods to protect the organization's overall security.

## Scenario

A security analyst inspects the organization's network and discovers four major vulnerabilities:

1. Employees share passwords.
2. The database administrator's password is the default one.
3. Firewalls have no rules set to filter incoming and outgoing network traffic.
4. Multi-factor authentication (MFA) is not used.

If these vulnerabilities are not addressed, the organization risks experiencing another data breach or other attacks in the future.

## Identified vulnerabilities

- **Shared passwords**: employees reuse the same credentials, increasing the risk of unauthorized access.
- **Default password**: the database admin account uses the factory default password, easy to guess.
- **Unfiltered network traffic**: firewalls lack rules to filter traffic entering and leaving the network.
- **No MFA**: accounts only rely on passwords, with no additional verification layer.

## Recommended hardening measures

- **Enforce strong, unique passwords** for all employees and administrative accounts.
- **Change default passwords** immediately and require periodic password updates.
- **Configure firewall rules** to filter incoming and outgoing network traffic.
- **Implement multi-factor authentication (MFA)** to add an extra layer of security to accounts.

## Why these measures are effective

- Strong passwords and MFA make it significantly harder for attackers to gain unauthorized access.
- Firewall rules help monitor and block suspicious traffic before it reaches the network.
- Regular hardening practices reduce the attack surface and prevent future breaches.

## Tools

- Network hardening tools
- Firewall configuration
- Security risk assessment template

## Contents

- Security risk assessment report (vulnerability analysis and hardening recommendations)

# Evaluación de Refuerzo de Redes

Actividad sobre prácticas de refuerzo de redes y evaluación de riesgos de seguridad.

## Descripción

Evaluación de riesgos de seguridad para una organización de redes sociales que recientemente sufrió una importante filtración de datos causada por vulnerabilidades no detectadas. El objetivo es identificar herramientas comunes de refuerzo de redes y proponer métodos para proteger la seguridad general de la organización.

## Escenario

Un analista de seguridad inspecciona la red de la organización y descubre cuatro vulnerabilidades importantes:

1. Los empleados comparten las contraseñas.
2. La contraseña del administrador de la base de datos es la predeterminada.
3. Los firewalls no tienen reglas establecidas para filtrar el tráfico que entra y sale de la red.
4. No se utiliza la autenticación multifactor (MFA).

Si no se toman medidas para abordar estas vulnerabilidades, la organización corre el riesgo de experimentar otra filtración de datos u otros ataques en el futuro.

## Vulnerabilidades identificadas

- **Contraseñas compartidas**: los empleados reutilizan las mismas credenciales, aumentando el riesgo de acceso no autorizado.
- **Contraseña predeterminada**: la cuenta de administrador de la base de datos usa la contraseña predeterminada de fábrica, fácil de adivinar.
- **Tráfico de red sin filtrar**: los firewalls carecen de reglas para filtrar el tráfico que entra y sale de la red.
- **Sin MFA**: las cuentas solo dependen de contraseñas, sin capa adicional de verificación.

## Medidas de refuerzo recomendadas

- **Exigir contraseñas seguras y únicas** para todos los empleados y cuentas administrativas.
- **Cambiar las contraseñas predeterminadas** de inmediato y exigir actualizaciones periódicas.
- **Configurar reglas de firewall** para filtrar el tráfico de red entrante y saliente.
- **Implementar autenticación multifactor (MFA)** para agregar una capa adicional de seguridad a las cuentas.

## Por qué estas medidas son eficaces

- Las contraseñas seguras y la MFA dificultan significativamente el acceso no autorizado por parte de los atacantes.
- Las reglas de firewall ayudan a monitorear y bloquear el tráfico sospechoso antes de que llegue a la red.
- Las prácticas de refuerzo periódicas reducen la superficie de ataque y previenen futuras filtraciones.

- Herramientas de refuerzo de redes
- Configuración de firewall
- Plantilla de evaluación de riesgos de seguridad
