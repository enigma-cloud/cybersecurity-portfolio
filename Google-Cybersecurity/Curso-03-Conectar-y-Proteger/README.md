# Evaluación de Riesgos - Red Social

## Escenario

Una organización de redes sociales sufrió una filtración de datos.

## Vulnerabilidades identificadas

- Compartición de contraseñas.
- Contraseña predeterminada del administrador.
- Firewall sin reglas.
- Ausencia de MFA.

## Controles recomendados

- MFA.
- Políticas de contraseñas.
- Configuración de firewall.

## Resultado esperado

Reducir accesos no autorizados y fortalecer la seguridad de la organización.
